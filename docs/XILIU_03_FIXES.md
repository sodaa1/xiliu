## 使用与边界

安装包：`dist/Xiliu-0.3.0-x64-setup.exe`，同目录 `.sha256` 文件可校验。无需删除已有用户数据重新安装。

“停止回复”是取消当前执行，不提供断点继续。同步外部请求尚未返回数据时，需要等待下一段流数据或配置的超时后完成释放；其他聊天仍可使用。停止不会撤销停止之前已经导入或保存的卡片。

模型调用通过本地虚拟 API 验证了完整 SDK / Graph / HTTP 链路，没有使用用户的真实密钥。实际供应商的密钥、账号权限和网络可用性需要在用户配置环境下确认。Windows 原生壳已编译，HTML5 文件导入路径已验证；当前环境没有进行交互式桌面窗口拖入测试。

Windows 拖入设置依据 [Tauri WebviewWindowBuilder 文档](https://docs.rs/tauri/latest/x86_64-pc-windows-msvc/tauri/webview/struct.WebviewWindowBuilder.html#method.disable_drag_drop_handler)。
