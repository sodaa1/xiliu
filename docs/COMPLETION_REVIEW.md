## 边界

当前不做 OCR 或外链全文抓取；本期已加入 PDF/DOCX 文字抽取与可选 embedding。Ask AI 使用记录的正文、摘要、来源与抽取文字；参考最长 38,000 字符，界面标明截取。

GitHub Trending 是公开 HTML，结构变化会显示来源失败并保留缓存。Feed Save 在内容创建事务内去重；运行记录展示状态与通用提示，完整报告在本机 automation-reports。调度依赖应用或既有 CLI 调度进程运行。

Markdown 和索引事务包含失败恢复；外部修改 Markdown 不自动触发重建。显式重建遇到损坏 Markdown 时先拒绝而不删除已有索引。断电不提供跨文件与 SQLite 的原子提交保证。
