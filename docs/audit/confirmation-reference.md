# Confirmation interaction reference

The existing Xiliu assistant MessageList, Modal and Feed form are the build target.
Use the current quiet canvas, existing secondary/primary buttons, modal focus trap,
Escape dismissal and form error text. The Refero craft-details reference requires
visible keyboard focus and specific action copy; no new visual tokens are added.

Show a review button in the persisted assistant message. Opening it shows the real
requested operation and target. The human confirms in the modal; an Agent cannot
approve the token. Disable confirmation while the HTTP request runs, then refresh
persisted messages and application data. Pending archive jobs display live status.
