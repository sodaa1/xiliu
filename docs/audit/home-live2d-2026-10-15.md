## Remaining asset and manual checks

The approved PNGs are illustrations, not rigged Cubism exports. No approved `.moc3` model or proprietary Cubism Core was present. Install Core and import separately exported Q/standing model folders as described in `web/public/companion/live2d/README.md` to exercise actual deformation, eye blink and artist-authored motions. The renderer lifecycle is tested with a boundary double; it does not establish visual fidelity of a real model.

This change does not create a Windows installer. Packaged native-window behavior (tray, minimize, monitor/DPI transitions, actual Live2D rendering) still needs manual acceptance with model assets. Existing native logic compiles and its unit tests pass.
