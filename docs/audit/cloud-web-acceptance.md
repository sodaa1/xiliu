# 完整网页版验收记录

验收日期：2026-10-17。功能分支：`codex/cloud-web-accounts`，基础版本 `9201c2a`。本次交付为可自行托管的 Docker 源码包；没有创建公共服务器，也没有改变现有 GitHub Pages 游客站或 Windows 0.4.4 安装包。

## 功能与边界

- 注册、登录、退出、管理员密码重置及可撤销 Cookie 会话；工作区、资料、附件、会话、后台任务和模型设置按账号隔离。
- 游客 `/demo/` 使用独立静态构建、示例资料与演示回复，不调用正式业务 API。
- 用户自有 API 配置独立加密。可选公共模型每账号累计 5 次；余额与请求幂等由服务端账本维护。已开始生成后停止或断开连接仍计次，未开始生成的连接失败返还。
- 为未来同步保留实体版本、删除标记和增量游标；本次没有桌面账号登录或双向同步。
- 云端关闭宿主进程、任意文件、自定义 Skill / MCP、AI Hot 和联网搜索。GitHub 资讯与链接标题保留受限公网访问。

## 独立审查

独立审查覆盖整个功能分支及最后验收改动，发现并修复：

1. 登录/注册外层请求体读取绕过通用超时与并发槽。现在身份请求读取自身有 4 个并发槽、30 秒总期限和 4096 字节上限，超时/断开/取消均释放槽。新测试先在原实现失败，修复后通过，覆盖未完成请求、第五个请求被拒、超时以及槽恢复。
2. 注册文案错误地允许短横线。现已与服务端字母、数字、下划线规则一致。

修复经独立只读复核通过，身份/限制测试 7 项由审查方独立重跑通过，无未解决审查发现。
