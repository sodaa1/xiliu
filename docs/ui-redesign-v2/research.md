## 三个可比较目标

预览是独立设计文件，使用标明的示例内容，没有调用产品接口。三个方向展示同一批资料并可切换 Assistant，差异以布局/排版/工作密度为主。

| 方向 | 核心结构 | 排版与使用 |
|---|---|---|
| A 连续工作台（推荐） | 204px 文字导航 + 344px 队列 + 弹性阅读面，详情操作固定在阅读栏顶部 | 14px UI、12px 元数据、24px 内容标题、16px 阅读正文；减少全宽重复标题和导航 |
| B 阅读优先 | 184px 安静侧栏 + 296px 索引 + 更宽居中的阅读版心；阅读时可折叠索引 | 16px 队列标题、28px 文档标题、18px/1.85 正文；阅读行长与操作条解耦 |
| C 列表优先 | 64px 图标导航 + 近全宽表格；选中资料后 520px 详情抽屉 | 13px/40px 紧凑行，标题、类型、标签、时间按列对齐；适合批量整理 |

三个方向共享：系统中英无衬线字体，400/500/600 三种字重；中性黑白灰，品牌紫仅限品牌图形，不再给导航/标签/全部按钮染紫；1px 分隔、6–10px 控件圆角、无大面积玻璃模糊。中文不套装饰标题字库、不加英文式负字距。

## 具体动效规格

- 导航 hover：背景 120ms，按下反馈 90ms；选中背景不连续闪动。
- 列表选择：120ms 表面切换；正文换页仅 160ms 透明度/4px 位移，避免整个列表重播。
- 详情抽屉：220ms ease-out，从右侧 12px 进入；可中断，关闭不阻塞下一次选择。
- 搜索/动作面板：180ms 透明度 + 0.985→1 缩放；Escape 与遮罩关闭，焦点返回触发按钮。
- 减少动态：禁用位移和缩放，状态即时更新；无粒子、无无限漂浮、无虚假 Agent 时间线。

用户已明确选择 **A 连续工作台**，作为正式重做的视觉目标。正式实现继续复用真实 API、会话与停止、权限确认、用户数据、首页主题/角色及 resize；不把预览里的示例内容放进产品源码。
