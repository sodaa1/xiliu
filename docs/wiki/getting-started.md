# 快速开始

先走通一条信息流，再按需要探索其他功能。息流把发现、收集、整理、提问和行动放在同一个空间。

## 三步上手

从 Feed 收藏一条资讯，在 Inbox 补充标签并归档，再打开资料点击 Ask AI。这条流程帮助你理解各模块之间如何连接；使用指南中可以随时重新开始引导。

## 主页快速提问

Today 中间的输入框可以直接开始对话。写下问题后发送，应用会打开 Assistant；正常模式需要先在设置中配置模型。

## 快速收集

主页输入框旁的添加按钮可以收集文字和链接到 Inbox。先记下来，再到收件箱编辑和归类；保存链接不代表已经抓取网页全文。

## 个人设置入口

点击主页头像可以修改昵称、头像和个人简介。修改后会体现在应用的个人展示中；这些资料不会自动成为模型对话内容。

## 游客演示与重置

演示版使用示例资讯和浏览器中的独立试用数据，助手回复明确标为演示。顶部可以重置体验；清除站点数据也会移除试用修改，演示不会读写桌面资料。

## 正常模式的第一步

安装桌面版或运行本地 Web 后，可直接使用资料整理功能。需要 AI 回复时再打开设置中的模型页，填写你自己的模型连接；演示版不要求也不接收真实 Key。
