# 模型连接

真实 AI 功能需要你自己的模型服务。游客演示的问答使用本地模板，模型页不会接收或保存真实 Key。

## 提供商与 API 地址 <!-- unavailable -->

在设置的模型页选择提供商，填写对应 API 地址。普通地址与订阅计划专用地址可能不同，应以你实际服务的配置为准。

## 模型名称与 API 密钥 <!-- unavailable -->

填写服务支持的模型标识和自己的 API 密钥，再保存连接。模型名称需精确匹配，连接出错时检查地址、认证和服务额度；不要把 Key 写进聊天或公开资料。

## 多连接与默认连接 <!-- unavailable -->

模型页支持维护多份连接配置，并选择默认连接。不同聊天可以选择其他可用连接，默认值用于没有单独覆盖的会话。

## 连接启停与会话选择 <!-- unavailable -->

不常用的连接可以暂停启用，保留配置以便之后恢复。会话模型列表只应选择当前可用连接，切换后后续问题使用新的配置。

## 本地检索与 embedding <!-- unavailable -->

知识库默认支持不依赖向量服务的全文和元数据检索。源码环境可以按配置启用专用 embedding 模型，为检索提供额外通道；没有配置也能先整理和查找资料。
