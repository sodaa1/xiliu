# 常见问题

遇到问题时先检查对应功能的前提与实际状态。以下说明也帮助你分辨游客演示与完整应用的差别。

## 模型无法回复

正常模式先检查设置中的提供商、API 地址、模型名称、Key 和服务额度，再重试。模型服务连接、资料抓取和资讯 MCP 是不同链路，一个可用不代表其他都可用。

## 资讯没有更新

查看 Feed 来源状态并尝试刷新，检查网络与服务配置。游客演示始终展示样例资讯，不是实时新闻阅读服务。

## 导入失败或正文为空

检查资料处理状态和文件格式，失败后可按提示重试。保存 URL 不等于成功抓取全文，扫描件需要 OCR，而当前应用尚不提供 OCR。

## 停止后仍看到操作结果

停止只请求结束当前生成，已经完成的写入不会撤销。外部请求可能到下一个数据片段或超时才释放，应检查回执判断实际结果。

## 演示与正式使用的差别

游客演示不调用模型、不上传文件、不执行自动任务和外部工具。安装或运行正常应用后，按指南配置相关服务，才可使用这些完整能力。
