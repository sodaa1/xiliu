# 外观与桌宠

调整阅读习惯，也可以在 Windows 使用独立桌面伴侣。网页与桌面共用外观说明，原生窗口能力带有桌面专属标记。

## 昵称、头像与个人简介

设置中的个人信息可以修改昵称、头像、邮箱和简介。保存后应用立即更新展示，实际数据保存范围见数据与备份指南。

## 主题、字体、字号和密度

在外观与阅读中选择浅色、深色或跟随系统，以及适合自己的字体和字号。密度控制内容间距，预览区域可以帮助你检查效果。

## 减少动态与恢复默认

减少动态会让页面切换等效果更安静，适合不希望界面频繁运动的用户。恢复默认外观只重置相关展示选项，不会清空资料库。

## 内置、留白与自定义背景

主页背景可以选择内置图片、留白，正常模式也能上传和管理自定义图片。图片有格式、大小和分辨率限制，演示仅提供内置与留白切换。

## 常驻桌宠的显示与置顶 <!-- desktop unavailable -->

Windows 桌面版可启用独立桌宠，控制显示、隐藏和保持置顶。进入设置的桌面伴侣区域操作，普通网页不会创建原生桌面窗口。

## 拖动、形态与分别缩放 <!-- desktop unavailable -->

桌宠可拖动到适合的位置，在 Q 版和常规比例之间切换，并分别保存缩放。桌面伴侣设置提供比例选项，不需要通过改变应用字号调整角色大小。

## 桌宠快捷聊天与 Inbox 收录 <!-- desktop unavailable -->

点击桌宠可展开快捷输入，把问题交给助手或把想法收进 Inbox。聊天仍使用应用中的模型配置，失败时可以回主窗口查看具体原因。

## Live2D 模型与图片表情 <!-- unavailable -->

内置角色使用图片表情，真正的 Live2D 形变需要另行导入兼容模型及 Core 资源。正常模式在外观设置导入文件夹；游客演示不上传模型，也不把静态表情称为真实 Live2D 动作。
