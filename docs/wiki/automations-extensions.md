# 自动任务与扩展

这些能力让正常应用连接更多工作流程。它们具有各自的运行条件，游客演示只提供说明，不运行后台任务或外部工具。

## 创建自动任务 <!-- unavailable -->

在设置的自动任务页填写名称、任务说明和执行时间。保存前检查模型与工具是否已配置，应用和调度服务需要处于可运行状态。

## 执行时间与时区 <!-- unavailable -->

时间输入配合所选时区决定任务触发时间。换设备或调整日程时应检查时区，避免把当地时间与服务端时间混淆。

## 启停、删除与运行记录 <!-- unavailable -->

可以暂停自动任务、重新启用或删除，并查看各次运行结果。成功与否以运行记录为准，保存了计划并不意味着任务已经执行。

## 安装 Skill <!-- unavailable -->

Skill 为助手提供特定任务的说明和资源，正常环境从本地数据目录读取。安装前确认来源与适用任务，再在助手中用 `/skill` 选择。

## 配置 MCP 服务 <!-- unavailable -->

MCP 将外部服务的工具连接给助手，每个服务有独立配置和运行条件。配置完后可通过 `/mcp` 选择，资讯联网与模型联网是不同调用链。

## 工具权限与人工确认 <!-- unavailable -->

助手操作受工具权限和确认规则约束，部分写入需要用户明确确认。确认前阅读对象和范围；应用权限本身不等于操作系统或网络沙箱。
