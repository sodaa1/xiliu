# Assistant 助手

在独立会话里提问，也可以从资料页带着参考开始。正常模式连接你配置的模型，游客模式只提供标明“演示回复”的本地模板。

## 新建、切换和删除会话

会话列表可以创建不同话题、切换历史和删除不再需要的聊天。各会话独立保存内容；删除前确认对象，停止回复与删除聊天并不是同一操作。

## 会话运行状态

每个聊天分别记录正在处理、完成或出错的状态。你可以在一个会话回复期间查看其他会话，停止操作只针对选中的运行任务。

## 输入、发送与模型切换

在输入框写下问题，按 Enter 发送，Shift+Enter 换行。模型选择器可以为当前会话切换可用连接，正常模式需要先在设置中启用相应配置。

## 资料引用与本轮参考

从 Feed 或资料详情点击 Ask AI，可以把选中的内容带入当前问题。发送前查看参考标题和正文，过长资料可能截断；引用不会自动代表模型已读过所有附件。

## Markdown 与思考过程

消息支持 Markdown 排版，运行时可以显示处理步骤和模型提供的思考内容。思考过程用于理解任务状态，是否存在以及详细程度取决于供应商和模型。

## 停止回复

点击输入框旁的停止按钮，请求中断当前会话的生成。已经完成的保存或删除不会被撤销，外部同步请求也可能等待下一段数据或超时后才释放。

## 操作回执与确认

助手执行应用操作后会展示结果回执，必要的写入先请求确认。阅读对象和范围再确认；只有通过实际写入校验的结果才说明操作成功。

## /clear 清除会话

在输入框发送 `/clear`，清除当前聊天内容并重新开始上下文。它不等于清空知识库；游客演示只清除对应的演示会话。

## /compress 压缩上下文 <!-- unavailable -->

发送 `/compress` 可在正常模式总结当前上下文，同时保留历史记录。压缩需要可用模型，结果为空或失败时保留原上下文；演示版不会调用真实压缩。

## /skill 使用技能 <!-- unavailable -->

输入 `/skill` 可以查看和选择本机已安装的技能，再附上任务。技能提供特定工作流程，不会绕过工具权限；游客演示不加载本机技能。

## /mcp 使用连接 <!-- unavailable -->

输入 `/mcp` 选择已配置服务，并描述希望完成的任务。连接可能需要账号、运行环境和网络，演示版不执行任何外部服务工具。

## 调整布局

会话侧栏和输入框的边缘提供拖动或键盘调整入口。尺寸按当前环境保存，适合在小屏阅读或长问题输入时调整工作空间。
