# 数据与备份

了解资料保存在哪里，才能安全地升级和迁移。正常 Web、桌面应用和静态演示的保存方式不同。

## 正常 Web 的资料位置 <!-- unavailable -->

本地 Web 的聊天、收件箱和知识库保存在运行 Python 服务的机器上，默认数据目录为项目 `.xiliu/`。浏览器只是访问界面，换浏览器不会自动获得另一台机器的资料。

## 浏览器偏好与试用数据

网页中的部分展示偏好保存在浏览器，演示资料也仅保存在当前站点的独立试用空间。清除站点数据会移除这些内容；浏览器不允许持久保存时会提示仅当前页面有效。

## 桌面数据目录 <!-- desktop unavailable -->

Windows 桌面版资料保存在 `%APPDATA%\io.xiliu.desktop`，部分偏好另有本机备份。可以在设置的数据页查看位置并复制路径，勿将开发目录与安装版目录混淆。

## 备份与升级 <!-- unavailable -->

升级前退出应用，备份完整数据目录，再进行安装或替换。不要为了升级删除资料；只复制单个数据库可能遗漏附件和其他配置。

## 演示重置与删除范围

演示顶部的重置按钮会清除试用修改和演示引导进度，恢复预置内容。它不会删除正常 Web 或桌面资料；确认前会说明即将移除哪些试用状态。

## 指南搜索与重新引导

使用指南支持按功能名或问题搜索，文章链接可以直接打开。想再次体验三步流程时，点击指南中的重新开始引导，现有真实资料不会因此被改写。
