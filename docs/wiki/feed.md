# 资讯

把外部发现与自己的资讯链接放在一起浏览。这里展示资讯卡片，长期保留的内容可以收藏到收件箱。

## 人工智能热点与 GitHub 热门项目

在资讯左侧切换人工智能热点或 GitHub 热门项目，查看对应来源的资讯。真实来源需要可用的联网服务，演示版展示的是预置样例。

## 来源状态与手动刷新

来源面板显示资讯服务是否可用和最近状态。点击刷新重新读取真实来源；演示版只刷新示例视图，不会获取实时新闻。

## 搜索与来源筛选

在资讯搜索框输入标题或内容关键词，并结合来源筛选缩小范围。清空搜索后回到完整列表，隐藏项需要开启对应显示选项才能查看。

## 添加与编辑我的资讯

选择添加资讯，填写链接、标题、摘要和标签，就能维护自己的阅读线索。手动资讯支持编辑，外部来源卡片的内容由来源管理。

## 隐藏与恢复资讯

卡片上的隐藏操作可以让不想继续看的外部资讯退出默认列表。手动资讯删除后也有恢复入口；查看隐藏项后可以把需要的卡片恢复。

## 收藏到收件箱

点击资讯卡片的收藏按钮，将该卡片的信息保存到收件箱。随后可以在那里补充正文、标签并归档；收藏不保证自动得到原网页全文。

## 资讯详情与摘要

打开资讯详情可以阅读卡片保存的摘要和来源链接。正常模式可按条件请求模型总结，演示模式提供标明来源的示例摘要。

## 从资讯引用提问

点击卡片上的引用提问，以当前资讯作为本轮参考打开助手。发出问题前可以检查参考内容；回复质量取决于已有资料和所选模型。
